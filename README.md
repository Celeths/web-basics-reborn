# Web Basics Reborn

Unlock web page functionality often reserved for JavaScript, by using the latest html and css standards with zero script required.

[![Patreon](https://img.shields.io/badge/Patreon-%23F96854.svg?style=for-the-badge&logo=patreon&logoColor=white)](https://www.patreon.com/cw/ProCrow) [![Ko-Fi](https://img.shields.io/badge/Ko--fi-%23F16061.svg?style=for-the-badge&logo=ko-fi&logoColor=white)](https://ko-fi.com/gwencrow)

Each core function is packaged as an independent module. No build step, no dependency, no import graph. Where something genuinely cannot be done without a script, the script is optional and only says what the markup cannot.

## Modules

| Module | What it does |
| --- | --- |
| [pure-css-nested-menu](modules/pure-css-nested-menu) | A branching menu at any depth. One open path at a time, three CSS rules, no ghost re-opens. |

## Using one

1. Take the module's folder, or just its stylesheet.
2. Link the stylesheet.
3. Write the markup its readme describes.
4. Add the optional script only if you want the accessibility layer.
